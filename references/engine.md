# Engine API

The engine lives in the project's `engine/` folder (copied from `template/engine/`). It is plain ES modules on the Canvas 2D API: the browser studio and the Node renderer run the same code, so what the user approves in the studio is what renders. Do not edit `engine/` for one video's needs; put project code in `scenes/`, `project.js`, and `theme.js`. Fix genuine engine bugs in the skill's `template/engine/` too.

All sizes are **design pixels** (the timeline's width/height, e.g. 1920×1080). The renderer scales to the output size, so never hard-code output resolution.

## Project files

```
project.js        fonts, images, scene registry, background/overlay layers
theme.js          palette + fonts (one place to restyle)
scenes/*.js       one module per storyboard "component"
storyboard.json   the plan in machine form (scripts read it)
src/timeline.json generated by timeline.py (never edit by hand; re-run the script)
public/           vo/, music/, sfx/, audio/mix.wav (generated)
engine/           the engine (render.js, studio.js, core/draw/transitions)
review/notes.json studio review notes
out/              stills, video.mp4, final.mp4, qc/
```

## project.js

```js
import { defineProject } from './engine/core.js';
export default defineProject({
  backgroundColor: '#f3ecdf',                     // base fill (video has no alpha)
  fonts: [{ family: 'Inter', weight: 600, src: 'node_modules/@fontsource/inter/files/inter-latin-600-normal.woff2' }],
  images: { logo: 'assets/logo.png' },            // preloaded -> s.assets.images.logo
  scenes: { title, explainer, outro },            // keys = storyboard "component"
  background(ctx, env) {},                         // optional, under every scene (does not transition)
  overlay(ctx, env) {},                            // optional, over everything: progress, captions, grain
  setup({ timeline, assets }) {},                  // optional one-time project setup
});
```

`env` = `{ w, h, scale, frame, t, fps, project }` (global time). Register one `fonts` entry per weight; use `.woff2`, `.woff`, `.ttf`, or `.otf`.

## Scene modules

```js
export default {
  setup({ w, h, fps, params, assets, scene, timeline }) { return { /* layout, precomputed paths */ }; },
  draw(ctx, s) { /* paint one frame */ },
};
```

`draw` receives the context already in design pixels and wrapped in `save/restore`. The scene context `s`:

| Field | Meaning |
|-------|---------|
| `s.w`, `s.h`, `s.fps` | design size, frame rate |
| `s.frame`, `s.t` | frames / seconds since the scene's sequence start (fractional allowed) |
| `s.duration`, `s.seconds` | scene length (includes both transition overlaps) |
| `s.inFrames`, `s.outFrames` | incoming / outgoing transition lengths |
| `s.params`, `s.state`, `s.assets` | storyboard params, `setup()` result, loaded images |
| `s.lines` | this scene's voice lines: `{ id, speaker, text, start, end }` (seconds, scene-relative) |
| `s.enter(delay, dur = 0.8, ease = EASE.enter)` | 0→1 entrance starting `delay` s in |
| `s.exit(dur = 0.5, ease = EASE.exit, lead = 0)` | 1→0, finishing at the outgoing transition's midpoint (minus `lead`) |
| `s.life(delay, dur, exitDur)` | `enter × exit` — an element's whole visibility |
| `s.spring(delay, SPRING.gentle)` | damped spring 0→1 (may overshoot with bouncy configs) |
| `s.line(n)` | `{ start, end, p, active, text }` for voice line `n` (0-based) — sync reveals to speech |
| `s.speaking()` | true while any line of this scene plays (drive mouths with `talk()`) |
| `s.globalFrame`, `s.globalT`, `s.timeline` | absolute time and the full timeline |

## core.js

- Math: `clamp`, `lerp`, `invLerp`, `smoothstep`, `interpolate(x, [a, b], [c, d], ease)`, `TAU`.
- Easing `EASE`: `linear`, `in/out/inOutQuad`, `in/out/inOutCubic`, `outQuart`, `outQuint`, `inOutSine`, `outExpo`, `inOutExpo`, `outBack`, and the motion-design set `enter` (fast-out, soft landing), `exit` (gentle accelerate), `move` (symmetric), `emphasized`; `EASE.bezier(x1, y1, x2, y2)` for custom curves.
- Springs: `spring(seconds, config)`, presets `SPRING.gentle | snappy | bouncy | heavy`.
- Randomness/noise: `rng(seed)` (`()`, `.range`, `.int`, `.pick`), `noise2(x, y, seed)` in [-1, 1], `fbm(x, y, seed, octaves)`, `hashString`.
- Rendering: `renderFrame(ctx, project, frame, scale, cache)`, `sceneAt`, `activeScenes`, `createLayer(w, h)` (offscreen canvas at pixel size).

## draw.js

Backgrounds and textures (cached per size/scale):

- `paper(ctx, w, h, { base, mottle, fibres, seed })` — mottled paper with fibres and fine grain.
- `stripes(ctx, w, h, { colors, width, angle, offset })` — diagonal stripes; animate `offset` for drift.
- `blueprint(ctx, w, h, { bg, line, major, step, drift, glow })` — night grid with glow.
- `vignette(ctx, w, h, { strength, color })`, `glow(ctx, x, y, radius, color, alpha)`.
- `grain(ctx, w, h, frame, { amount })` — per-frame film grain (also stops gradient banding in H.264).

Strokes and paths:

- `sketch(ctx, points, { p, width, color, seed, amp, t, boil, double })` — hand-drawn stroke that draws on (`p` 0→1) and optionally "boils" (`boil` = redraws per second, 6–10 looks hand-animated).
- `wobble(points, opts)`, `partial(points, p)`, `pointAt(points, p)` → `{ x, y, angle }`, `resample(points, spacing)`, `strokePath(ctx, points, { width, color, dash })`.
- Shapes as point lists: `circlePoints(cx, cy, r, { overshoot })`, `rectPoints(x, y, w, h)`; `roundRect(ctx, x, y, w, h, r)` (path).

Text:

- `font(size, weight, family)` → CSS font string; `wrapText(ctx, text, maxWidth)` (spaces for Latin, per character for CJK).
- `text(ctx, str, x, y, { size, weight, family, color, align, baseline, maxWidth, lineHeight, letterSpacing, alpha })` → `{ width, height, lines }`.
- `wordsIn(ctx, str, x, y, p, { size, weight, family, color, align, maxWidth, rise, overlap, blur })` — staggered word entrance.
- `typewriter(ctx, str, x, y, p, t, { size, family, color, caret })` — typed text with blinking caret.
- `countUp(from, to, p, { decimals, prefix, suffix, separator })` → formatted string.

Annotation and chrome:

- `callout(ctx, p, { x, y, tx, ty, label, sub, color, accent, size, t })` — pulsing dot, leader line draws on, label reveals.
- `chapter(ctx, label, p, { x, y, size, color, accent })` — small title with drawn underline.
- `progressRing(ctx, p, { x, y, r, color, track, label })`.
- `captions(ctx, env, { size, weight, family, colors: { speaker: color }, box, bottom, maxWidth })` — burned-in captions from the timeline's voice lines.

Camera and images:

- `camera(ctx, w, h, { x, y, zoom, rotate }, () => { … })` — look at a point; `parallax(ctx, w, h, cam, depth, fn)` for depth layers.
- `imageCover(ctx, img, x, y, w, h, { focusX, focusY })`, `brushReveal(ctx, img, x, y, w, h, p, { seed, rows, brush })` — paint an image in with soft brush dabs.

Character rig:

- `mascot(ctx, { x, y, size, t, body, outline, cheek, look: [dx, dy], mood: 'happy'|'neutral'|'sad'|'surprised', mouth, seed, squash, wave, boil })` — breathing, bobbing, blinking, looking, talking, waving blob character. Use it as-is for friendly explainers or as a pattern for a custom character.
- `blink(t, seed)` (0→1 eyelid), `talk(t, speaking, seed)` (mouth openness).

Colour: `rgba(hex, a)`, `mixColor(a, b, t)`, `hexToRgb(hex)`.

Filters: `setBlur(ctx, px)` — blur in design pixels. Canvas `filter` ignores the transform, so never write `ctx.filter = 'blur(6px)'` directly (it would shrink at 4K); reset with `setBlur(ctx, 0)` or `ctx.restore()`.

## Transitions (storyboard `transition_out`)

| type | params | feel |
|------|--------|------|
| `cut` | — | instant; plan it on a beat |
| `fade` | `through: '#000'` (dip) | entering scene fades in over the opaque exiting one |
| `dissolve` | `blur` | focus pull: A defocuses forward, B sharpens in |
| `zoom` | `center: [x, y]`, `direction: 'in'|'out'`, `blur` | push through the frame |
| `slide` | `direction: left|right|up|down`, `blur` | both scenes travel; blur follows speed |
| `wipe` | `angle` or `direction`, `feather` (0–1), `edge: '#hex'` | feathered wipe at any angle |
| `iris` | `center: [x, y]` (0–1), `ring: '#hex'`, `ringWidth`, `zoom`, `from` | lens opens on a subject and dives in |
| `tear` | `direction`/`angle`, `paper: '#hex'`, `seed` | ragged paper tear reveals the next scene |

All accept `seconds` and `ease` (an `EASE` name). Default easing is chosen per type.

## render.js

```
node engine/render.js --check                       key frames draw without errors (+ ms per frame)
node engine/render.js --stills auto [--scale 0.5]   PNGs of scene/transition middles -> out/stills/
node engine/render.js --stills 0,120,240            specific frames
node engine/render.js --size 1920x1080              out/video.mp4 + out/final.mp4 (with public/audio/mix.wav)
    [--workers N] [--motion-blur N] [--crf 16] [--preset slow] [--from F --to F] [--draft] [--no-mux]
```

`--size` must match the design aspect ratio. `--draft` = half size, fast encode.

## studio.js

`node engine/studio.js [--port 4600] [--open]` serves the project on 127.0.0.1. Keys: Space play/pause, ←/→ one frame, Shift+←/→ one second, `[`/`]` previous/next scene, Home/End, L loop scene, M mute, S safe areas, N add note. Notes API: `GET/POST /__api/notes`, `PATCH/DELETE /__api/notes/<id>`; notes live in `review/notes.json` as `{ id, frame, time, scene, text, status: open|resolved, resolution? }`. Dotfiles (such as `.env`) are never served.
