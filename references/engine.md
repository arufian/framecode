# Engine API

The engine lives in the project's `engine/` folder (copied from `template/engine/`). Scenes are **p5.js sketches** (p5 2.x): the engine owns one offscreen p5 instance and calls each scene's `draw(p, s)` every frame, then composites the result (scene layers, transitions, overlay) onto the frame. The browser studio and the renderer (headless Chrome, driven by Puppeteer) run the same code, so what the user approves in the studio is what renders. Do not edit `engine/` for one video's needs; put project code in `scenes/`, `project.js`, and `theme.js`. Fix genuine engine bugs in the skill's `template/engine/` too.

All sizes are **design pixels** (the timeline's width/height, e.g. 1920×1080). The engine sets p5's pixel density to the output scale, so `p.width`/`p.height` are always the design size and every shape stays sharp at 4K. Never hard-code the output resolution.

## Project files

```
project.js        fonts, extra images, scene registry, background/overlay layers
theme.js          palette + fonts (one place to restyle)
scenes/*.js       one p5 module per storyboard "component"
storyboard.json   the plan in machine form (scripts read it)
src/timeline.json generated by timeline.py (never edit by hand; re-run the script)

public/           vo/, music/, sfx/, audio/mix.wav (+ stem-*.wav), footage/<name>/, images/, media.json (generated)

.puppeteerrc.cjs  Puppeteer downloads only chrome-headless-shell
review/notes.json studio review notes
review/mix.json   music/SFX levels from the studio sliders (mix_audio.py reads and updates it)

```

## project.js

```js
import { defineProject } from './engine/core.js';
export default defineProject({
  backgroundColor: '#f3ecdf',                     // base fill (video has no alpha)
  fonts: [{ family: 'Inter', weight: 600, src: 'node_modules/@fontsource/inter/files/inter-latin-600-normal.woff2' }],
  images: { logo: 'assets/logo.png' },            // extra p5.Image -> s.assets.images.logo (prefer media.py add)
  scenes: { title, explainer, outro },            // keys = storyboard "component"
  background(p, env) {},                           // optional, under every scene (does not transition)
  overlay(p, env) {},                              // optional, over everything: progress, captions, grain
  setup({ timeline, assets }) {},                  // optional one-time project setup
});
```

Ledger art and images (from `public/media.json`, written by `media.py visuals`) load automatically into `s.assets.images.<name>`, and footage into `s.assets.footage.<name>`; `images` entries in `project.js` win on a name clash.

`env` = `{ w, h, scale, frame, t, fps, project }` (global time; `env.project.assets` has the same images and footage). `background` and `overlay` draw with p5 like scenes, on the global clock. Register one `fonts` entry per weight; use `.woff2`, `.woff`, `.ttf`, or `.otf`.

## Scene modules

```js
export default {
  setup({ w, h, fps, params, assets, scene, timeline }) { return { /* layout, precomputed paths */ }; },
  draw(p, s) { /* paint one frame with the p5 instance p */ },
};
```

`setup` runs once and returns plain data (layouts, point lists); it gets no `p`. The scene context `s`:

| Field | Meaning |
|-------|---------|
| `s.w`, `s.h`, `s.fps` | design size, frame rate |
| `s.frame`, `s.t` | frames / seconds since the scene's sequence start (fractional allowed) |
| `s.duration`, `s.seconds` | scene length (includes both transition overlaps) |
| `s.inFrames`, `s.outFrames` | incoming / outgoing transition lengths |
| `s.params`, `s.state`, `s.assets` | storyboard params, `setup()` result, `s.assets.images` (`p5.Image`) and `s.assets.footage` (clips) |
| `s.lines` | this scene's voice lines: `{ id, speaker, text, start, end }` (seconds, scene-relative) |
| `s.enter(delay, dur = 0.8, ease = EASE.enter)` | 0→1 entrance starting `delay` s in |
| `s.exit(dur = 0.5, ease = EASE.exit, lead = 0)` | 1→0, finishing at the outgoing transition's midpoint (minus `lead`) |
| `s.life(delay, dur, exitDur)` | `enter × exit` — an element's whole visibility |
| `s.spring(delay, SPRING.gentle)` | damped spring 0→1 (may overshoot with bouncy configs) |
| `s.line(n)` | `{ start, end, p, active, text }` for voice line `n` (0-based) — sync reveals to speech |
| `s.speaking()` | true while any line of this scene plays (drive mouths with `talk()`) |
| `s.globalFrame`, `s.globalT`, `s.timeline` | absolute time and the full timeline |

## p5 in scenes

Before every `draw(p, s)` (and every `background`/`overlay` call) the engine:

1. sets the pixel density to the output scale (only when it changes) and clears the canvas to transparent;
2. reseeds `p.random()`, `p.randomGaussian()`, and `p.noise()` from the scene id (`'background'` / `'overlay'` for the project layers);
3. maps `p.frameCount` (whole frames), `p.millis()`, and `p.deltaTime` to the caller's clock (scene-relative for scenes, global for the project layers);
4. resets `angleMode` to `RADIANS` and wraps the call in `p.push()`/`p.pop()`, unwinding any `push()` the scene forgot.

After the call it composites the p5 canvas into the frame. So:

- **Style state starts fresh every frame.** Set fill, stroke, text settings, and blend mode in `draw`; wrap local changes in `p.push()`/`p.pop()`.
- **Randomness is stable.** The same sequence of `p.random()` calls returns the same values every frame, so `p.random()` places things (confetti, stars) and `p.noise(i, s.t * k)` moves them. Branches change the sequence: take all of an element's random values before any `continue`/`return`, or precompute layouts in `setup()` with `rng(seed)`. Call `p.randomSeed(n)` inside `draw` for a second independent stable sequence. Never `Math.random`.
- **The engine owns the canvas and the loop.** Never call `createCanvas`, `resizeCanvas`, `pixelDensity`, `frameRate`, `loop`, `noLoop`, `redraw`, `saveCanvas`, or `remove`, and never assign `p.setup`, `p.draw`, or event handlers (`mousePressed`, `keyPressed`, …).
- **No loading or DOM in scenes.** No `loadImage`/`loadFont`/`loadJSON`/`createImg`, no DOM elements (`createDiv`, sliders), no `p5.sound`, no `createCapture`/`createVideo`. Register assets in `project.js`.
- **Text.** Fonts registered in `project.js` are addressed by family: `p.textFont(THEME.font); p.textWeight(800); p.textSize(96); p.textAlign(p.CENTER, p.CENTER); p.text(str, x, y)`. Register every weight you use. `p.textWidth(str)` measures. For staggered or typed text use `wordsIn`/`typewriter` below.
- **Images.** `s.assets.images.logo` is a `p5.Image`: `p.image(img, x, y, w, h)`, `p.tint(255, 128)`, or `imageCover(p, img, …)`.
- **Footage.** `footage(p, s.assets.footage.city, s.t, x, y, w, h, { from, rate, loop, fit })` draws the clip's frame for clip time `from + t * rate` (see "Footage" below). Never `createVideo` or an HTML `<video>`: seeking is not frame-exact.
- **Opacity and blur of a group.** `p.push(); opacity(p, a); setBlur(p, 6 * (1 - a)); …; p.pop();` — `opacity` multiplies the 2D context's `globalAlpha`, `setBlur` scales the blur to the output size. Avoid `p.filter(BLUR)`: it re-filters the whole canvas every frame.
- **Offscreen buffers and 3D.** `buffer(p, key, w, h, { webgl })` returns a persistent `p5.Graphics` sized in design px at the current output scale (re-created when the scale changes); draw into it every frame, then `p.image(g, x, y)`. `baked(p, key, w, h, paint)` paints once per scale (static textures; use `rng()` inside). `{ webgl: true }` gives a WEBGL buffer for 3D (origin at the buffer's centre; lights, `box`, `sphere`, `model`). Never call `p.createGraphics` in `draw` (it leaks canvases and WebGL contexts). Inside buffers, take values from `p.random()`/`p.noise()` or `rng()`: `g.random()` is unseeded.
- **Mixing with the 2D context.** `p.drawingContext` is the raw `CanvasRenderingContext2D` (gradients, `globalCompositeOperation`, clip paths); p5 transforms apply to it. Save/restore around raw state changes (`p.push()`/`p.pop()` does both), or p5's cached fill/stroke can go stale. All `draw.js` helpers already do this.

## core.js

- Math: `clamp`, `lerp`, `invLerp`, `smoothstep`, `interpolate(x, [a, b], [c, d], ease)`, `TAU`.
- Easing `EASE`: `linear`, `in/out/inOutQuad`, `in/out/inOutCubic`, `outQuart`, `outQuint`, `inOutSine`, `outExpo`, `inOutExpo`, `outBack`, and the motion-design set `enter` (fast-out, soft landing), `exit` (gentle accelerate), `move` (symmetric), `emphasized`; `EASE.bezier(x1, y1, x2, y2)` for custom curves.
- Springs: `spring(seconds, config)`, presets `SPRING.gentle | snappy | bouncy | heavy`.
- Randomness/noise: `rng(seed)` (`()`, `.range`, `.int`, `.pick`), `noise2(x, y, seed)` in [-1, 1], `fbm(x, y, seed, octaves)`, `hashString` — independent of p5, safe in `setup()` and buffers.
- Rendering: `renderFrame(ctx, project, frame, scale, cache)`, `renderFrameReady(…)` (async: redraws until every footage frame it uses is loaded; the renderer uses it), `sceneAt`, `activeScenes`, `createLayer(w, h)` (offscreen canvas at pixel size).

## draw.js

Every helper takes the p5 instance `p` first (a `p5.Graphics` or a raw 2D context also works) and draws through its 2D context, so helpers and p5 calls share transforms (`p.translate`, `p.scale`, `camera`). `ctxOf(p)` returns that context.

p5 helpers:

- `opacity(p, a)` — multiply the opacity of everything drawn next (inside `p.push()`/`p.pop()`).
- `setBlur(p, px)` — blur in design pixels. Canvas `filter` ignores the transform, so never write `p.drawingContext.filter = 'blur(6px)'` directly (it would shrink at 4K); reset with `setBlur(p, 0)` or `p.pop()`.
- `buffer(p, key, w, h, { webgl })`, `baked(p, key, w, h, paint, { webgl })` — offscreen `p5.Graphics` (see "p5 in scenes").

Backgrounds and textures (cached per size/scale):

- `paper(p, w, h, { base, mottle, fibres, seed })` — mottled paper with fibres and fine grain.
- `stripes(p, w, h, { colors, width, angle, offset })` — diagonal stripes; animate `offset` for drift.
- `blueprint(p, w, h, { bg, line, major, step, drift, glow })` — night grid with glow.
- `vignette(p, w, h, { strength, color })`, `glow(p, x, y, radius, color, alpha)`.
- `grain(p, w, h, frame, { amount })` — per-frame film grain (also stops gradient banding in H.264).

Strokes and paths:

- `sketch(p, points, { p, width, color, seed, amp, t, boil, double })` — hand-drawn stroke that draws on (option `p` 0→1) and optionally "boils" (`boil` = redraws per second, 6–10 looks hand-animated).
- `wobble(points, opts)`, `partial(points, p)`, `pointAt(points, p)` → `{ x, y, angle }`, `resample(points, spacing)`, `strokePath(p, points, { width, color, dash })`.
- Shapes as point lists: `circlePoints(cx, cy, r, { overshoot })`, `rectPoints(x, y, w, h)`; `roundRect(p, x, y, w, h, r)` (path on `p.drawingContext`; p5's own `p.rect(x, y, w, h, r)` also rounds corners).

Text:

- `font(size, weight, family)` → CSS font string; `wrapText(p, text, maxWidth)` (spaces for Latin, per character for CJK).
- `text(p, str, x, y, { size, weight, family, color, align, baseline, maxWidth, lineHeight, letterSpacing, alpha })` → `{ width, height, lines }`.
- `wordsIn(p, str, x, y, progress, { size, weight, family, color, align, maxWidth, rise, overlap, blur })` — staggered word entrance.
- `typewriter(p, str, x, y, progress, t, { size, family, color, caret })` — typed text with blinking caret.
- `countUp(from, to, progress, { decimals, prefix, suffix, separator })` → formatted string.

Annotation and chrome:

- `callout(p, progress, { x, y, tx, ty, label, sub, color, accent, size, t })` — pulsing dot, leader line draws on, label reveals.
- `chapter(p, label, progress, { x, y, size, color, accent })` — small title with drawn underline.
- `progressRing(p, progress, { x, y, r, color, track, label })`.
- `captions(p, env, { size, weight, family, colors: { speaker: color }, box, bottom, maxWidth })` — burned-in captions from the timeline's voice lines.

Camera and images:

- `camera(p, w, h, { x, y, zoom, rotate }, () => { … })` — look at a point; `parallax(p, w, h, cam, depth, fn)` for depth layers. Plain p5 transforms (`p.translate`/`p.scale` in a `push`/`pop`) work the same way.
- `imageCover(p, img, x, y, w, h, { focusX, focusY })`, `brushReveal(p, img, x, y, w, h, progress, { seed, rows, brush })` — paint an image in with soft brush dabs.
- `footage(p, clip, t, x, y, w, h, { rate = 1, from = 0, loop = false, fit = 'cover'|'contain'|'fill', focusX, focusY })` — draw a footage clip (below). Returns `false` while no frame is loaded (studio only).

Character rig:

- `mascot(p, { x, y, size, t, body, outline, cheek, look: [dx, dy], mood: 'happy'|'neutral'|'sad'|'surprised', mouth, seed, squash, wave, boil })` — breathing, bobbing, blinking, looking, talking, waving blob character. Use it as-is for friendly explainers or as a pattern for a custom character.
- `blink(t, seed)` (0→1 eyelid), `talk(t, speaking, seed)` (mouth openness).

Colour: `rgba(hex, a)` (a CSS string p5's `fill`/`stroke` accept), `mixColor(a, b, t)`, `hexToRgb(hex)`. p5's `p.color`, `p.lerpColor`, and `colorMode(HSB)` work too.

## Footage

`media.py visuals` turns every ledger video into a JPEG frame sequence (`public/footage/<name>/00000.jpg …`, at the clip's frame rate capped at the project fps, covering the design size) and lists it in `public/media.json` as `{ dir, frames, fps, width, height, seconds }`. The engine (`engine/media.js`) makes each a clip object in `s.assets.footage`:

- `footage(p, clip, t, …)` picks frame `floor((from + t * rate) * clip.fps)`, held at the last frame (or wrapped with `loop`). `clip.seconds` is the extracted length: keep `from + scene length × rate` inside it.
- Frames load on demand and are cached (36 per clip) with 12 prefetched ahead in the playback direction. A frame that is not loaded yet counts as a miss: the renderer (`renderFrameReady`) waits for it and redraws, so renders are frame-exact and identical across runs and workers; the studio shows the nearest loaded frame and redraws when it arrives.
- Everything about drawing applies: transforms, `camera`, `opacity`, `setBlur`, clip paths, blend modes, buffers.

## Transitions (storyboard `transition_out`)

| type | params | feel |
|------|--------|------|
| `cut` | — | instant; plan it on a beat |
| `fade` | `through: '#000'` (dip) | entering scene fades in over the opaque exiting one |
| `dissolve` | `blur` | focus pull: A defocuses forward, B sharpens in |
| `zoom` | `center: [x, y]`, `direction: 'in'|'out'`, `blur` | push through the frame |
| `slide` | `direction: left|right|up|down`, `blur` | both scenes travel; blur follows speed |
| `wipe` | `angle` or `direction`, `feather` (0–1), `edge: '#hex'` | feathered wipe at any angle |
| `iris` | `center: [x, y]` (0–1), `ring: '#hex'`, `ringWidth`, `zoom`, `from` | lens opens on a subject and dives in |
| `tear` | `direction`/`angle`, `paper: '#hex'`, `seed` | ragged paper tear reveals the next scene |

All accept `seconds` and `ease` (an `EASE` name). Default easing is chosen per type. During a transition both scenes draw (each through the p5 surface) into their own layers, and the transition composites them.

## render.js

```
node engine/render.js --check                       key frames draw without errors (+ ms per frame)
node engine/render.js --stills auto [--scale 0.5]   PNGs of scene/transition middles -> out/stills/
node engine/render.js --stills 0,120,240            specific frames
node engine/render.js --size 1920x1080              out/video.mp4 + out/final.mp4 (with public/audio/mix.wav)
    [--workers N] [--motion-blur N] [--crf 16] [--preset slow] [--from F --to F] [--draft] [--no-mux]
    [--browser <path to Chrome/Chromium>]
```

`--size` must match the design aspect ratio. `--draft` = half size, fast encode.

How it works: render.js serves the project on a random local port, opens `engine/studio/headless.html` in headless Chrome (one browser context per worker), and each page draws its frame range with the same engine and p5 code as the studio. Raw RGBA frames are posted back and piped to one ffmpeg per worker; the segments are concatenated and the frame count is verified. It tries `chrome-headless-shell` first, then Puppeteer's Chrome, then an installed Chrome; `--browser` or `FRAMECODE_BROWSER` picks one explicitly. Page errors print with the scene file and line; a page that stops producing frames (an endless loop) fails the run after a timeout instead of hanging.

## studio.js

`node engine/studio.js [--port 4600] [--open]` serves the project on 127.0.0.1. Keys: Space play/pause, ←/→ one frame, Shift+←/→ one second, `[`/`]` previous/next scene, Home/End, L loop scene, M mute, S safe areas, N add note. Notes API: `GET/POST /__api/notes`, `PATCH/DELETE /__api/notes/<id>`; notes live in `review/notes.json` as `{ id, frame, time, scene, text, status: open|resolved, resolution? }`. Dotfiles (such as `.env`) are never served.

Level sliders: when the mix has fresh stems (`mix_audio.py` writes them), the transport shows **music** and **SFX** sliders (−24 to +6 dB). The SFX stem drives the clock; music (and VO) follow it, re-synced when they drift over 60 ms. Music and SFX play through Web Audio gain nodes set to the slider level minus the level the stems were mixed at (`mixedMusicDb`, `mixedSfxDb`). Each change is saved through `GET/POST /__api/mix` (`{ musicDb, sfxDb }`) to `review/mix.json`, and the audio badge reads "audio level changed — remix before render" until `mix_audio.py` runs. Without stems the studio plays `mix.wav` and hides the sliders.
